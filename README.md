# Baleseng Automotive — Truck Spares & Accessories

Online store for quality truck parts. Built from the WebDevPro Ultra Max 5 master template.

## Features
- Full product catalogue with categories
- Shopping cart (localStorage)
- Checkout with **Cash on Delivery (COD)** and **WhatsApp order**
- Floating WhatsApp assistant
- Responsive PWA-ready site
- Black / red brand theme matching the logo

## Development
```bash

```

## Production
```bash
npm run build
```

## Deploy (Vercel)
1. Push this repo to GitHub
2. Import into Vercel
3. Framework: Vite · Build: `npm run build` · Output: `dist`
4. `vercel.json` is included for SPA routing

## Future e-commerce
Checkout currently sends order details to WhatsApp. You can later add WooCommerce, PayPal, or other payment plugins.
